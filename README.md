# Qun Dai — Academic Homepage

A private, local-first academic homepage draft for Qun Dai. The site uses a compact profile column and text-first sections for biography, research interests, dated news, publications, education, and honors.

## Preview locally

Double-click `index.html`, or start a local server in this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html` — page content and structure
- `styles.css`, `updates.css`, and `card-theme.css` — responsive academic layout, card styling, and print styles
- `assets/profile.png` — profile photograph supplied by Qun Dai
- `assets/swufe-emblem.png` — official SWUFE emblem downloaded from the university website
- `assets/infmasking-flow-chart.png` — official InfMasking workflow image from the paper's code repository
- `assets/favicon.svg` — local favicon
- `preview.png` — desktop preview generated during QA

The site contains no analytics, external fonts, build tooling, or deployment workflow. It has not been uploaded or published.
